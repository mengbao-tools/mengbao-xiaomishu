## 这是什么

Discuz 这套界面十几年没大改，用久了有几个具体的别扭：图片得一张张点开看、帖子得一页页翻、板块和广告刷屏、收藏的人散在收藏夹里找不到、评论要看就得一路滚到底。

这个脚本把这几件事各做了一次处理，全部塞进几颗可拖动的悬浮球里，不需要改论坛任何设置。

**不改变论坛本身**：不接管登录、不改积分、不动帖子内容。所有改动都发生在你本机浏览器的显示层。

## 功能

**🖼️ 图片预览**
列表页标题下直接预览图片；全屏画廊网格浏览；大图按原尺寸显示，可拖拽平移、双击退出；支持连续加载整页所有帖子的图。

**📄 自动翻页**
列表页滚到底自动加载下一页，不用点「下一页」；不用的时候随时可以关掉。

**🔍 搜索过滤**
给不想看的板块打标记，一键隐藏；搜索页支持关键词过滤，长标题不折行。

**⭐ 收藏管理**
收藏用户和帖子，按分组管理；收藏用户的帖子行会高亮，一眼找得到。

**💬 评论侧栏**
右侧边栏展开评论流，支持翻页、关键词过滤、最小字数过滤，宽度可拖。

**✍️ 评分助手**
评分表单自动填满分，重复评分自动去重。

**👁️ 已读标记**
浏览过的帖子自动标记，三态可选：关闭 / 变灰划线 / 只变灰，底色也能自己调。

**🖥️ 窄屏模式**
嫌 1200 版心太宽，可以一键压回 960。只作用于版块列表、导读、帖子、搜索页这四类阅读页；首页、个人中心设置、勋章、排行榜等页面保持论坛原样，切到全屏档时自动放开。

**🙋 头像身份**
评论区显示自定义头像和昵称，9 个格子，点哪格填哪格，可拖拽换位。

## 快速上手

球都停在页面**左侧**，但不会四个一起出现：脚本按页面类型决定挂哪几颗，用不上的功能不占位置，免得挡住内容。

- **版块列表页**：看图球、翻页球（2 颗）
- **搜索页 / 导读页**：看图球、翻页球、过滤球（3 颗）
- **收藏页 / 我的主题**：看图球、翻页球（2 颗）
- **帖子详情页**：增强球（1 颗）
- **小黑屋 / 我的回复**：翻页球（1 颗）
- **首页、个人中心**：不挂球

能拖，拖到屏幕边缘会自动校正位置，松手后的位置会被记住。四颗球分别管什么：

| 球 | 颜色 | 出现在哪些页面 | 左键 | 右键 |
|---|---|---|---|---|
| 看图球 | 蓝 | 版块列表页、搜索页、导读页、收藏页、我的主题 | 开启/停止持续加载图片 | 停止并收起所有预览 |
| 翻页球 | 紫 | 版块列表页、搜索页、导读页、收藏页、我的主题、小黑屋、我的回复 | 加载下一页 | 开启/关闭自动翻页 |
| 过滤球 | 绿 | 搜索页、导读页 | 展开过滤面板 | 打开屏蔽词设置 |
| 增强球 | 近白 | 帖子详情页 | 展开功能面板 | 打开评论侧边面板 |

第一次装好会弹一张引导卡片，把四颗球各自的用法和手势过一遍。之后想再看，点设置弹窗右上角的「📖 使用帮助」。

## 设置

从脚本管理器（油猴 / 暴力猴）的菜单进入「设置」。主要能调：

- **通用**：窄屏模式、已读标记（关闭 / 变灰划线 / 只变灰）、已读底色、翻页延时、按发帖时间排序、右键用户名跳转目标
- **看图**：画廊背景色、卡片色、收藏高亮色、预览图数量与高度
- **收藏**：收藏馆入口、分组管理
- **工具**：头像设置、重置位置、清除缓存、导出/导入配置、恢复默认
- **白名单**：脚本只在你添加到白名单的站点生效。不在白名单的站点也能从菜单里的「白名单管理」单独加域名，不用先进论坛；「恢复默认」不会清空白名单

颜色类设置**保存即生效**，不用刷新。只有「按发帖时间排序」和域名白名单需要刷一次页面——它们要重新请求一个排好序的页面，不是前端能改的。

配置全部存在本地，不上传任何服务器。收藏、头像、浏览历史按论坛账号独立存放。

## 更新

脚本的元数据里配了 `@updateURL`，管理器会定期检查新版本并提示更新。

安装链接用的是固定版本地址（`@v1.6` 这种），不经 `@main`，装到的就是对应版本的原文，不受 CDN 缓存影响。

需要知道的一点：`@updateURL` 指向的是 `@main`，而 jsDelivr 对 `@main` 最长有 12 小时缓存。所以**已装用户收到更新提示的时间**会比实际发布会晚一些，这属正常，已经装好的版本不受影响。

想立刻用上新版，直接装带版本号的地址就行，比如 `…@v1.6/mengbao.user.js`——它锁定的是那一版，不受缓存影响。

## 常见问题

**装完没有任何反应？**
检查两点：脚本管理器是否启用、论坛域名是否在脚本的匹配范围内。也可以先确认浏览器有没有拦住管理器本身的注入。

**悬浮球挡住了内容？**
直接拖走，位置会记住。也可以在设置里点「重置位置」恢复默认。

**换了账号，收藏全没了？**
不是丢了——收藏、头像、浏览历史是按账号分开存的，切到另一个账号看到的是那个账号自己的数据。

**同一台电脑装两个管理器会重复吗？**
不会，脚本开头做了实例保护，同页只跑一份。但还是建议只留一个。

## 这是什么

Discuz 这套界面十几年没大改，用久了有几个具体的别扭：图片得一张张点开看、帖子得一页页翻、板块和广告刷屏、收藏的人散在收藏夹里找不到、评论要看就得一路滚到底。

这个脚本把这几件事各做了一次处理，全部塞进几颗可拖动的悬浮球里，不需要改论坛任何设置。

**不改变论坛本身**：不接管登录、不改积分、不动帖子内容。所有改动都发生在你本机浏览器的显示层。

## 功能

**🖼️ 图片预览**
列表页标题下直接预览图片；全屏画廊网格浏览；大图按原尺寸显示，可拖拽平移、双击退出；支持连续加载整页所有帖子的图，翻页途中不会乱序抢请求；预览缓存记住 500 个帖子，翻回十几页以内不用重新加载。

**📄 自动翻页**
列表页滚到底自动加载下一页；论坛自带的「下一页」按钮也接管，点它同样走脚本翻页，已读标记和图片预览不中断。翻页球上显示这次一共翻了几页。所有页面请求统一走全局池排队（并发 4、间隔 80 ms、60 秒内同地址复用、缓存 120 条），翻页优先级高于看图与热度。

**🔍 搜索过滤**
给不想看的板块打标记，一键隐藏；搜索页支持关键词过滤，长标题不折行。

**⭐ 收藏管理**
收藏用户和帖子，按分组管理；收藏用户的帖子行会高亮，一眼找得到。

**💬 评论侧栏**
右侧边栏展开评论流，支持翻页、关键词过滤、最小字数过滤，宽度可拖。

**✍️ 评分助手**
评分表单自动填满分，重复评分自动去重。

**👁️ 已读标记**
浏览过的帖子自动标记，三态可选：关闭 / 加底色 + 划线 / 只加底色，底色也能自己调。记录上限 500 条，覆盖十几页，往回翻不会把读过的又当成未读。

**🖥️ 宽版模式**
论坛把窄档版心从 1200 改成了 960，勾上这一项就按 1200 排，各页版心统一。它靠页面根元素的变量与一个 class 全站生效，首页、个人中心、排行榜一起变宽；论坛自己切到全屏自适应档时自动放开，不覆盖。

**🔥 帖子热度与已购**
列表和详情页的帖子行内显示浏览、回复、已购。单独开关，关掉就不再后台取数。

**🏆 排行榜版块筛选**
帖子排行榜页在榜单上方多出一条版块筛选，列出本榜的版块和各自条数。左键屏蔽该版块，右键只看该版块（可同时只看多个，再右键同一个退回全部）。序号仍保留它在总榜的真实名次；五种榜单 × 四个时段各记一套选择，切换分类互不影响。

**🙋 头像身份**
评论区显示自定义头像和昵称，9 个格子，点哪格填哪格，可拖拽换位。

## 快速上手

球都停在页面**左侧**，但不会四个一起出现：脚本按页面类型决定挂哪几颗，用不上的功能不占位置，免得挡住内容。

- **版块列表页**：看图球、翻页球（2 颗）
- **排行榜页**：看图球（1 颗）
- **搜索页 / 导读页**：看图球、翻页球、过滤球（3 颗）
- **收藏页 / 我的主题**：看图球、翻页球（2 颗）
- **帖子详情页**：增强球（1 颗）
- **小黑屋 / 我的回复**：翻页球（1 颗）
- **首页、个人中心**：不挂球

能拖，拖到屏幕边缘会自动校正位置，松手后的位置会被记住。四颗球分别管什么：

| 球 | 颜色 | 出现在哪些页面 | 左键 | 右键 |
|---|---|---|---|---|
| 看图球 | 蓝 | 版块列表页、排行榜页、搜索页、导读页、收藏页、我的主题 | 开启/停止持续加载图片 | 停止并收起所有预览 |
| 翻页球 | 紫 | 版块列表页、搜索页、导读页、收藏页、我的主题、小黑屋、我的回复 | 加载下一页 | 开启/关闭自动翻页 |
| 过滤球 | 绿 | 搜索页、导读页 | 展开过滤面板 | 打开屏蔽词设置 |
| 增强球 | 近白 | 帖子详情页 | 展开功能面板 | 打开评论侧边面板 |

第一次装好会弹一张引导卡片，把四颗球各自的用法和手势过一遍。之后想再看，点设置弹窗「通用设置」标题行右侧的「📖 使用帮助」。

## 设置

从脚本管理器（油猴 / 暴力猴）的菜单进入「设置」。主要能调：

- **通用**：宽版模式、帖子热度与已购、已读帖子（关闭 / 加底色 + 划线 / 只加底色）、按发帖时间排序、已读帖子底色、翻页延时、右键用户名跳转目标
- **看图**：画廊背景色、卡片色、收藏高亮背景色、收藏高亮标题色、预览图数量、预览图高度
- **收藏**：收藏馆入口、分组管理
- **工具**：头像设置、重置位置、清除缓存、导出/导入配置、恢复默认
- **白名单**：脚本已预置 2 个论坛域名，只在这些域名下生效。不在白名单的站点也能从菜单里的「白名单管理」单独加域名，不用先进论坛；「恢复默认」不会清空白名单

颜色类设置**保存即生效**，不用刷新。只有「按发帖时间排序」和域名白名单需要刷一次页面——它们要重新请求一个排好序的页面，不是前端能改的。

配置全部存在本地，不上传任何服务器。收藏、头像、浏览历史按论坛账号独立存放。

## 更新

脚本声明了 `@updateURL`（指向 `main` 分支的 `mengbao.user.js`），管理器会自动检查新版本，安装后无需手动重装即可收到后续更新。

想升级就直接装带版本号的地址，比如 `…@v1.8/mengbao.user.js`——固定版本地址锁定的就是那一版原文，不受 CDN 缓存影响。

装哪个地址都一样带 `@updateURL`，管理器看到 `main` 上有新版本会提示或自动更新；想固定停在某一版，需要在管理器里关掉这个脚本的自动更新。

## 常见问题

**装完没有任何反应？**
检查两点：脚本管理器是否启用、论坛域名是否在脚本的匹配范围内。也可以先确认浏览器有没有拦住管理器本身的注入。

**悬浮球挡住了内容？**
直接拖走，位置会记住。也可以在设置里点「重置位置」恢复默认。

**换了账号，收藏全没了？**
不是丢了——收藏、头像、浏览历史是按账号分开存的，切到另一个账号看到的是那个账号自己的数据。

**同一台电脑装两个管理器会重复吗？**
不会，脚本开头做了实例保护，同页只跑一份。但还是建议只留一个。

## 说明

- 只读浏览增强，不修改论坛数据
- 所有配置存本地，无任何数据上传
- 域名白名单机制：只在你指定的论坛站点生效，其他网站不加载
- 脚本只针对当前站点维护，选择器按该站实测 DOM 确定，不承诺兼容其他 Discuz 论坛
- 根目录的 `mengbao.user.js` 就是当前正式版 v1.8，文件名带 `.user.js` 是为了让脚本管理器识别并弹安装页

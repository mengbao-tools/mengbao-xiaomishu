一、三步快速上手

1
打开任意板块列表页

脚本自动生效。帖子下方会出现图片缩略图，屏幕左侧出现悬浮球。板块列表页上是翻页球（紫）和看图球（蓝）两个；搜索页/导读页多一个过滤球（绿）；帖子详情页则是增强球（近白）。

2
点一下悬浮球试试功能

先点最下面的翻页球左键，加载下一页；再点看图球的左键，把整页的图都加载出来。想看全屏，点帖子下方的缩略图即可。

3
打开设置调整偏好

油猴菜单里的「设置」。画廊背景色、卡片色、收藏高亮背景和标题色都能自定义；收藏用户在设置里的「收藏馆」入口卡片进入。

三、全部功能一览

萌宝看图

多场景支持：版块列表页、搜索页、导读页、收藏页、用户主题页都能直接预览图片。

  • 点击缩略图打开全屏画廊，画廊是一整面格子墙，每格一张图
  • 点格子进单张大图，图片按窗口适配：小图保持原始尺寸不放大，大图等比缩到窗口内、整张完整可见
  • 切图用普通滚轮，缩放用 Ctrl + 滚轮（0.3–5 倍）；大图状态不接管拖动，想 1:1 看细节就用它放大
  • 顶部条上有旋转按钮，点一次转 90°
  • 退出有三种：双击图片、点顶部那一整条、按 Esc；小图四周的空白也能点出去
  • 不同帖子的图之间用一条分隔线隔开，不会混成一片
  • 关闭大图回到列表后，刚才看的那张会闪一圈琥珀色光圈帮你定位
  • 画廊背景色、卡片色可自定义；已加载的图片本地缓存，下次打开更快

设置与导入导出

所有配置都在设置面板里调整，支持全量导出/导入，换设备一键迁移。

  • 设置弹窗防误关：点遮罩不会关，只有「取消 / 保存设置」能退出
  • 颜色类设置保存后立即生效，不用刷新页面；排序、白名单等少数项仍需刷新
  • 「恢复默认」清空全部记录并自动刷新，不需要手动刷；站点白名单会保留
  • 收藏、头像、浏览历史、过滤词均按账号独立，换账号各看各的
  • 收藏馆支持单独导出/导入，可以只搬收藏这一块
  • 全量导出含参数、收藏、评分、收藏用户与站点白名单；不含悬浮球位置、看图缓存和已读历史
  • 有「调试日志」开关，排查问题时打开
  • 右上角「📖 使用帮助」可重新弹出新手上手引导

萌宝搜索 / 过滤

左键开板块过滤面板筛板块，右键开屏蔽词设置（支持精确、正则与排除词）。

  • 过滤词语法：广告 含词即藏、=求资源 精确匹配、/公告/ 正则匹配、!置顶 排除词
  • 支持「仅过滤当前板块」作用域
  • 过滤词弹窗有「取消」按钮——点取消不保存，不会误改
  • 过滤配置按账号独立：多账号登录各筛各的

收藏用户

楼层、列表页、资料页、个人主题页与个人回复页都能点星星收藏用户。

  • 收藏后他的帖子在列表页和搜索结果页都自动高亮（蓝底橙标题）
  • 高亮颜色可在设置里自定义
  • 所有收藏用户集中在独立的「收藏馆」弹窗里管理，不在通用设置里
  • 支持分组管理（拖拽排序、右键重命名/删除）、导出导入

浏览历史（已读标记）

你看过的帖子标题会自动变灰，下次再刷到一眼就知道「这个我看过了」。

  • 覆盖版块列表页、搜索结果页、个人主题页三处，翻页后新加载的行也会自动补上
  • 三态可选：关闭 / 变灰划线 / 只变灰，默认「变灰划线」。只加已读态、不做高亮，收藏用户的名字仍保持收藏色
  • 底色可在设置里改，改完保存即生效，搜索结果页同样跟随

窄屏模式

嫌 1200 版心太宽，可以一键压回 3.4 时代的 960。

  • 只作用于版块列表、导读、帖子、搜索页四类阅读页，默认关闭
  • 首页、个人中心设置、勋章、排行榜保持论坛原样——这几页内部有定宽组件，收窄后必错位
  • 导航条、页头 logo、右上用户信息、页脚边缘一起收窄，不是只窄中间而两边错位
  • 切到论坛「全屏」档时自动放开，不会叠加

评论侧边面板

右侧边栏实时显示帖子评论流，增强球右键可打开。

  • 支持评论翻页
  • 支持关键词过滤
  • 评论列表可按最小字数过滤，太短的评论自动隐藏
  • 面板宽度可用滑条调整

萌宝翻页

两种模式：左键加载下一页（接在列表后面），右键开自动翻页，一页页追到末页。

  • 翻页后自动联动搜索面板与看图缓存
  • 支持调整翻页延时（0–10 秒），防止请求过快
  • 评论面板的翻页栏有「尾页」，可直接跳到最后一页
  • 小黑屋页也支持持续加载

自定义头像昵称

评论侧边面板和收藏馆里可以用自己的头像和昵称。

  • 固定 9 个槽位，点哪一格就放进哪一格，空着的槽位保留位置
  • 可拖拽调整顺序：拖到空格是移动，拖到已有头像的格子是两者交换；删掉的格子留空、后面不前移
  • 不再自带内置头像，全部由自己添加；本地压缩，不上传服务器
  • 评论区、收藏馆共用同一套头像

右键点击用户名

右键点任意用户名，弹出快捷菜单，直达对方主页。

  • 五处都能用：列表页、搜索结果页、帖子详情页、收藏馆、评论侧边面板
  • 默认去「个人资料」，可在设置里改成「个人主题」或「个人回复」
  • 跳转地址带完整参数，点「个人主题」直接落到对方的主题列表
  • 不想用可在设置里选「关闭」，右键恢复浏览器原生菜单

四、设置面板详解

打开方式：油猴菜单里的「设置」。面板分四块：通用设置、萌宝看图、收藏馆入口、底部按钮区。

⚙️通用设置

窄屏模式 把论坛版心从 1200 压回 960。默认关闭。只作用于版块列表、导读、帖子、搜索页；首页、个人中心、勋章、排行榜保持论坛原样，切到全屏档时自动放开。保存后会提示当前页是否已生效。
已读标记 浏览过的帖子怎么标记：关闭 / 变灰划线 / 只变灰。默认「变灰划线」。改完保存即生效，搜索结果页同样跟随。
已读标记底色 已读帖子整行的底色，只对未收藏的帖子生效。默认 #f0f0f0。 默认 #f0f0f0
按发帖时间排序 开启后，所有板块自动按发帖时间倒序排列，永远看最新的。默认开启。
翻页延时（秒） 自动翻页时每页之间的等待间隔，防止请求过快。范围 0–10，默认 5。
右键点击用户名 右键点用户名弹出的快捷菜单去哪个页面：个人资料 / 个人主题 / 个人回复，最后一项「关闭」表示不接管右键、保留浏览器原生菜单。默认「个人资料」。

画廊卡片色 画廊里每张图片格的底色 默认 #f8fafc
收藏高亮背景 列表页收藏用户那一行的整行底色 默认 #dbeafe

预览图高度 单张预览图的高度，范围 120–320。默认 200。 默认 200

⭐萌宝收藏（入口）

收藏馆入口 设置里只放一张卡片，显示「收藏馆」和当前的「N 位用户 · M 个分组」，右侧一个「打开」按钮。
收藏馆弹窗 点开「打开」进入独立弹窗，宽 900px。从上到下是标题行（含「✏️ 编辑」与右上角 ×）、分组胶囊行、用户胶囊列表、三个管理按钮。拖胶囊可排序；拖到上方分组 tab 上松手即归入该组；右键胶囊进入该用户主页。
三个管理按钮 新建分组、导出、导入，都在收藏馆弹窗底部。
批量编辑 点标题行右侧「✏️ 编辑」进入勾选模式，工具条展开：全选 / 移入分组 / 删除选中 (N) / 取消。移入分组时弹窗选目标，「未分组」表示移出分组；批量移动后自动退出编辑态。

📍 重置位置四个悬浮球立刻回到默认位置，不用刷新
🧹 清除缓存清空看图模块已缓存的图片
📤 导出配置全部配置导出成 JSON 到剪贴板

底部还有一行：左边是「调试日志」开关（排查问题用，即时生效，不用刷新），右边是「取消 / 保存设置」。
右上角：「📖 使用帮助」——点了会重新弹一遍新手上手引导卡片；旁边的「ℹ️ 关于」显示当前版本、作者、仓库与使用指南地址。

五、界面入口在哪

左侧悬浮球

固定在屏幕左边，从下往上依次是翻页（📄）、看图（🖼️）、增强（⚡）、过滤（🎯）。全部可拖动。

油猴菜单

浏览器右上角油猴图标 → 萌宝小秘书，里面有两项：🌐 白名单管理 和 设置。

设置面板

从油猴菜单「设置」进入。宽 600px，含通用设置、看图配色、收藏馆入口、6 个按钮。

白名单管理

从油猴菜单「🌐 白名单管理」进入。默认已内置常用站群域名，可自行增删；不在名单里的站点不加载。这个入口不依赖当前页面，人在任何网站上都能打开它加域名，不用先打开目标论坛。填了无效内容会拒绝保存并提示，不会静默变回默认域名。

评论侧边面板

帖子详情页里，右键点增强球（⚡）打开。显示实时评论流，可翻页、可按字数过滤，面板宽度用滑条调整。

画廊

点任意帖子下方的缩略图进入。顶部标题栏显示帖子标题和「共 N 张」计数。

六、弹窗与数据约定

弹窗防误关

白名单、过滤词、通用设置、头像设置等主要弹窗统一规则：

  • 点遮罩不会关闭弹窗
  • 只能点「取消」或「保存 / 确定 / 导入」退出
  • 「取消」不保存任何改动，无副作用

数据按账号隔离

以下数据全部按登录用户 ID 分开存，换账号各看各的：

  • 收藏用户、评分记录
  • 浏览历史、已读标记
  • 过滤词配置、头像
  • 四个悬浮球的位置和折叠状态

七、1.0：起点

1.0 是脚本的第一个正式发布版，能力骨架在这一版定下来；后面的 1.1 到 1.4 都是在这套骨架上修补，没有推翻重做。所以本指南以 1.5 为准来写功能，版本变化从 1.0 这个起点往下排。

1.0 定下来的能力

  • 四颗悬浮球：看图、翻页、过滤、增强
  • 全屏图片画廊与单张大图查看器（滚轮切图、Ctrl + 滚轮缩放）
  • 列表页持续翻页、搜索页板块过滤与关键词黑名单
  • 收藏用户（收藏馆 + 分组管理）与收藏帖子
  • 评分弹窗自动填满分、评论侧边面板
  • 浏览历史已读标记、自定义头像昵称
  • 域名白名单管理、全量配置导出/导入

下面四节怎么读

按「你在使用中会注意到什么变化」来列，不按代码顺序。开发期那些 beta 迭代过程不在指南里展开——只讲 1.0 之后每个正式版改了什么。

八、1.0 → 1.1 有什么变化

1.1 动的主要是「看图」和「评分」两块，都是实际用起来会觉得别扭的地方。这里按「你会注意到什么」来列，不按代码顺序。

大图不再缩到刚好装下，改成原尺寸

以前大图会等比缩到「整张刚好塞进屏幕」。一张整屏截图放到满屏时，图顶到边、四周一点缝都不剩——想退出都没地方点。现在改成按原始像素显示：不放大也不缩小，居中摆着，超出屏幕的部分自己溢出。

特别大的图（三千多像素宽那种）默认只能看到中间一块，想看边缘用 Ctrl + 滚轮缩小（0.3–5 倍）。这条在 1.2 又调整回去了，见下一节「1.1 → 1.2」。

退出大图：双击、点顶部条、Esc

以前只有「点图片外面那一圈黑」能退出，整屏截图铺满时这一圈根本不存在。现在三个出口：

  • 双击图片——单击不退出，避免手滑划走
  • 点顶部那一整条——含计数区域，条上任何空白都能点
  • Esc

小图四周仍有留白，点空白照样能退。关闭按钮也从「只有从帖子列表进来才显示」改成一直显示。

顶部条重新做了一遍

高度 56 → 52，渐变收得更干脆，不再是糊一层黑；底部加了一条极细的白线做分界。计数从白底胶囊改成纯文字，亮图黑图都压得住。

按钮从「深底 + 白边」改成玻璃感的白描边，鼠标移上去只提亮、不再整颗放大跳动；关闭键单独区分，移上去变暖红，一眼看出是退出。

拖动功能取消了

原尺寸下本来能按住拖动，但看图这件事本身就是看中间，拖来拖去反而容易误操作。现在不拖了，光标也不再是抓手。

评分自动填满分

打开评分弹窗时，分数直接填到这一项的上限，你只选理由、点确定。上限是从评分下拉选项里读的（论坛没把它写在输入框的 max 属性里），有几项评分就各填各的。

论坛的 ajax 偶尔会把值刷回 0，脚本会在 250ms 和 900ms 各补一次；你自己改数字或点下拉，脚本立刻停手。

重复评分不再叠三条提示

对同一个帖子重复评分时，以前会同时出现论坛弹窗、红色 toast、深色提示三条。现在脚本这边不弹了，只把「👍 评分」按钮标成已评，屏幕上只留论坛那一个带「确定」的弹窗。其他评分错误仍会给红色提示。

个人主题页也有已读标记了

以前只有版块列表页和搜索结果页会标已读，点进某个人的「个人主题」列表，看过的帖子还是正常颜色。现在这一页也标了——灰底、标题变灰加划线，不做高亮，收藏用户的名字仍保持收藏色。

判定前提不变：得先打开过那个帖子才会变灰。

九、1.1 → 1.2 有什么变化

1.2 没有加新功能，主线是三件事：收藏馆的编辑与归组交互重做、下线「收藏关键词」、以及修掉一批看起来「功能坏了」的隐性 bug。照样按「你会注意到什么」来列，不按代码顺序。

「收藏关键词」下线了

以前帖子页右侧的评论面板上有「评论区 / 收藏馆」两个标签页，收藏馆那一页用来存关键词、按关键词找帖子。1.2 起这块整体移除。

  • 评论面板现在只剩评论，不再有标签切换
  • 收藏馆弹窗底部的「🔍 收藏关键词 N 个」入口一并去掉
  • 本地残留的关键词数据会在脚本启动时自动清掉，不用手动删

收藏馆：编辑不再单独占一行

以前「✏️ 编辑」按钮独占一行，下面再跟一条工具条，弹窗上半部分很挤。现在：

  • 「✏️ 编辑」放进标题行右侧，和右上角的 × 并排，非编辑态不占额外高度
  • 点「编辑」后工具条才整条展开：全选 / 移入分组 / 删除选中 (N) / 取消
  • 底部原来那行「关闭」删掉了，统一用右上角 ×（点遮罩、按 Esc 也照样能关）

编辑态可以直接「移入分组」

以前要换分组只能一个个拖。现在勾选一批用户后，点「移入分组」弹出分组选择面板，点目标分组就整批搬过去，搬完自动退出编辑态——因为列表会变，保留选中容易误删看不见的条目。

另外「未分组」的提示改成「已把 N 位用户移出分组」，不再说成移入一个叫「未分组」的组。

拖胶囊换分组：不再弹新窗口，光标也不再变禁止

拖拽修了两个问题：

  • 拖到空白处松手，以前浏览器会当成纯文本新开一个窗口搜索「uid:455002」；现在拖拽数据改成自定义类型，不会再触发
  • 拖动过程中光标中途显示 ⊗（禁止），但分组 tab 其实已经高亮——现在拖胶囊期间临时关掉分组 tab 自身的拖拽属性，从拿起胶囊到松手全程都是可移动光标

落点行为不变：拖到自定义分组 tab 归组、拖到「未分组」移出分组、拖到「全部」明确拒绝。

胶囊不再「鼠标一划过就变宽」

以前鼠标停在胶囊上会展开「切换分组 / ✕」两个图标，胶囊变宽，把后面的胶囊挤到第二行，整片列表跟着跳。现在胶囊宽度恒定，那些图标改成了编辑态的勾选框——只在你要批量操作时才出现。

分组多到放不下时，改成横向滚动

分组 tab 原来会换行，组一多就把弹窗撑高。现在锁成单行、左右滚动（滚动条隐藏），切到靠右的分组再重画也不会跳回开头。tab 改成浅灰底、胶囊仍是白底描边，两层能分清。

大图改成「整张看得见」

1.1 把大图改成了按原始像素显示，结果超大图（比如 1536×2048）在 1080 高的屏幕上只能看到中间一块，四周被裁掉，想退出都找不到边。1.2 改回按窗口适配：

  • 比窗口大的图，等比缩到窗口内，整张完整可见、不裁剪
  • 比窗口小的图，保持原始尺寸，不放大
  • 左右留白从 56px 收到 24px，横图能多显示一点
  • 想 1:1 看细节，仍然用 Ctrl + 滚轮放大

评论面板空白修复

1.2 早期版本里，帖子页的评论面板会变成只有头像、「N 条评论」标题和一条宽度滑条，中间全空。原因是模板里多包了一层 <template>，被运行时编译当成原生元素，把分页行和评论列表整块吞掉了。修复后列表正常显示，分页也能用。

搜索页宽度和论坛对齐了

搜索页的内容宽度从 1400 收回到 1200，和论坛列表页、首页、帖子页的版心一致，四页左右边缘完全重合（47 / 1247）。搜索页本身没有 #wp 容器，所以把外层 #ct 也一并收进版心；卡片左右各 12px 的内边距去掉，边缘更齐。

收藏星标不再挂错地方

以前打开短消息（do=pm）、提醒（do=notice）这类页面，右上角「当前登录用户」名字后面也会多出一个收藏星标。原因是这些页面和「个人资料页」共用同一个地址参数。现在只认资料页和个人主题页，其它子页面不再挂星标。

十、1.2 → 1.3 有什么变化

这一版主要做了三件事：砍掉用不上的功能、把头像做顺、把「改了设置要刷新」这个别扭的地方改掉。

「缩小显示」整套下线

增强球面板顶部那对「正常显示 / 缩小显示」胶囊已移除，帖子内图片恢复与不开脚本时一致的显示。原因很直接：这个开关和「点图进大图」的功能重叠，用得很少，却要在面板里常年占一行。

内置头像全部移除，改成 9 格自己搭

以前自带的「萌 / 桃」两个内置头像和「恢复内置默认头像」按钮都删了。现在是 9 个空格位，点哪一格就放进哪一格，不再强制从第一个开始往后排。

支持拖拽换位：拖到空位是移动，拖到已有头像的格子是两者交换。删掉一个头像后那格留空，后面的不往前挤。

设置改完不用再刷新了

画廊背景色、画廊卡片色、收藏高亮背景、收藏高亮标题、已读标记底色、已读删除线这 6 项，以及「已读帖子标记」总开关，保存后当场生效。以前要手动刷一次页面才看得到效果。

「恢复默认」也改顺了：以前点完要等 1.5 秒才自动刷新，而这个窗口里任何一次保存都会把旧值写回去，出现「点了恢复默认却没重置」。现在点完弹窗立即关闭、期间的保存一律拒收，随后页面自动刷新。

仍需要刷新的只有「按发帖时间排序」（它要重新请求一个排好序的页面）和域名白名单（脚本启动时就定下来了）。

预览图可以调大小了

新增「预览图数量」和「预览图高度」两个设置。前者控制标题下并排显示几张，后者控制单张图的高度（120–320）。嫌列表太挤就调矮一点、少放几张。

已读标记能自己配色

已读行底色可以改，「已读加删除线」可以单独关掉。只在搜索结果页也一起跟随设置——之前那一页是写死的，设置改了它不认。

几个别扭的地方

  • 打开头像设置不再全选「萌宝」：以前一进弹窗，昵称框就是选中状态，打第一个字就把整段替换了。
  • 拖头像松手不再弹图片窗口：以前拖完在弹窗外松手，浏览器会按「拖入一张图片」新开一个窗口显示它。
  • 设置弹窗窄了一点、控件靠右：宽度 640 → 600，输入框和色块贴到右边界，第二列右边不再挂一大片空白。
  • 头像弹窗定稿为 460px（中途试过 548、500 两个宽度），九格间距拉开，昵称框与「萌宝」两个字高度对齐，删掉了多余的「面板头像设置」标题行。
  • 评论面板的翻页栏加回「尾页」：顺序是「页码框 / 总页数 · 上一页 · 下一页 · 尾页」，数字和斜杠之间也拉开了距离。

支持在线更新了

元数据里加了 @updateURL 和 @downloadURL，指向 jsDelivr 的地址。装上之后，脚本管理器可以自己检查新版本。

十一、1.3 → 1.4 有什么变化

这一版开了个新开关、收了个旧账：给嫌 1200 太宽的人一个窄屏模式，把两个已读复选框合成了一个。

窄屏模式：版心能回到 960

论坛的「窄」档现在就是 1200，3.4 时代的 960 已经回不去了。这版在设置里加了一个「窄屏模式」开关，默认关闭，想窄就自己窄。

它只作用于版块列表、导读、帖子、搜索页这四类用来阅读的页面。首页、个人中心设置、勋章、排行榜保持论坛原样——这几页内部有定宽组件（首页的门户幻灯片、双栏模板右栏固定 1010），压到 960 必然错位，与其修一半不如整体不动。

收窄的不是中间那一条：导航条、页头 logo、右上角用户信息、搜索栏、页脚边缘会一起收到 960，不会出现「正文窄了、页头还停在 1200」的错位。切到论坛的「全屏」档时自动放开，不用手动关。

已读标记合成一个下拉

以前是「已读帖子标记」和「已读加删除线」两个复选框，能勾出「划线开着、标记却关着」这种其实什么都不会发生的组合。现在合成一个下拉：关闭 / 变灰划线 / 只变灰。

原来存的两个值会自动换算成新的三态，不用重新设置一遍。

几个小地方

  • 增强球改近白：默认色从偏灰改成 #f8fafc。没直接用纯白，是因为纯白会和论坛白底融成一片、只剩一圈细边框，认不出那是个球。
  • Vue 换生产版：Console 里那条「development build」警告不再出现，每次加载也从约 500KB 降到约 140KB。已经装过的需要卸载重装一次——脚本管理器的 @require 有缓存。
  • 设置弹窗控件对齐：复选框原来贴标签左对齐、下拉框贴着右边界，一列里三种控件右边参差不齐。现在统一在标签右侧的剩余空间居中。
  • 首次安装引导多了一行：新装用户看到的引导卡里会说明窄屏模式。老用户不会重弹这张卡。
  • 「新」角标：设置里的「窄屏模式」挂了个「新」字，过了 11 月 24 日自动消失。

修掉的几个 bug

  • 「我的帖子 / 我的收藏」顶部多出来的星标：那两页被误判成个人资料页，顶部的用户名旁边凭空挂了一个收藏星标。
  • 窄屏时页头没跟着收：logo 和右上角用户信息停在 1200 不动，跟收窄后的正文对不上。
  • 保存窄屏后看不出生效没有：以前 toast 只说「设置已保存」，现在会说明适用范围、以及当前这一页有没有生效。

十二、1.4 → 1.5 有什么变化

这一版主要在收口：换机、换版本时那份配置备份终于能用了，资料页的收藏星标回到了它该在的位置，几处会误导人的提示也改了口径。

旧版导出的配置能导进来了

以前用 1.0 导出的备份，粘进新版导入框会被整批拦下，提示「检测到无法识别的配置项」。原因有两个：1.0 的导出会把没设置过的项也写成空值，新版把这些空值当成坏键；收藏用户的排序表特意做成「按登录账号分开存」的结构，新版又不认识这种形状。

现在两类都能过——空值直接跳过、不参与校验，排序表的旧结构也认。导入完会告诉你导进了几项、忽略了几个已经下线的旧设置（内置头像、评论面板收藏这类）。

导出的文件更干净了

以前导出的 JSON 里一堆「键存在、值是空」的项，看着像配了几十项，实际大半没设过。现在只写真正设置过的项。

弹窗也把范围说清楚了：不含悬浮球位置、看图临时缓存与已读历史。这三样本来就不进备份，写出来是为了避免「导出等于全备份」的误解。

资料页的收藏星标回到头像旁

有一段时间，别人资料页上的收藏星标看着像不见了。不是没挂，是挂错了地方：落到「统计信息 好友数 / 回帖数」那一行的小字里，灰色空心小星夹在小字中间，等于隐形。

现在挂回资料页顶部的用户名栏，也就是头像右侧那一块——1.0 到 1.2 一直挂在这里。找不到才退回到正文里的用户名链接。

评论面板的总页数不再跟着离谱

偶尔会碰到论坛分页显示「/ 548368 页」这种数字，一帖明明只有几十条回复。脚本现在认一个必然成立的判断：页数不可能超过回复数，因为每页至少有一楼。超过就按回复数重算，所以真实存在的大帖（比如两千条回复）不会被误伤。

触发时脚本会把原始值、帖子编号和回复数记在本机，不进配置、也不进备份，下次再出现能回头查。

权限不够的帖子不再反复重试

阅读权限不足的帖子，脚本抓不到正文，会显示「⚠️ 未找到帖子内容 [重试]」。以前它会自己反复重试，一直在刷。现在失败一次就停在那儿，想再试就点旁边的 [重试]。

几个说清楚的地方

  • 关于入口：通用设置的标题行多了「ℹ️ 关于」，能看版本、作者、仓库和指南地址。脚本管理器的菜单项也带上了版本号。
  • 大图提示：「放大后可拖动」原来在缩放后面单独列着，现在并成一句「Ctrl+滚轮缩放（放大后可拖动）」，意思更连贯。
  • 白名单保存提示：补了「其它已打开的页面也要刷新」——白名单在页面加载时读取，只刷当前这一页，别的标签页还是旧的。
  • 窄屏模式说明：把适用范围写进了提示里，省得每次翻指南。
  • 收藏提示：从「收藏成功」改成「已收藏该帖」，明确是帖子还是用户。

1.5 还修了这几处

都不改功能，只是把细节修顺。

  • 用户主题页 / 回复页也能收藏了：这两类地址里带 view=me，之前被当成「自己的列表页」直接跳过，星标不出现。现在带 uid 的 view=me 认作对方的空间页，星标挂在顶部用户名旁。
  • 收藏后名字会变蓝：以前只有星标变实心、用户名不变色。现在帖子楼层、评论侧栏、版块列表、搜索结果都能正确高亮，评论面板滚动加载出来的评论也一样。
  • 楼层跳转不再被顶部条压住：评论面板点「跳转」后，目标楼层会被顶部红条盖住一截。现在按顶部条的实际高度让位，头像和用户名完整露出来。
  • 看图进度不再出现「278/270」：分子和分母口径统一了，完成数按帖子去重，分母取实时识别到的帖子数，不会再出现分子比总数大。
  • 手动点过论坛的「下一页」也能继续翻：论坛自己翻页后会把「下一页」链接换成伪地址，脚本照旧去请求就会报「连接被中断」。现在先找真正的下一页地址，找不到就按页码往后推，确实到末页才停。

十三、1.5 → 1.6 有什么变化

这一版主要在收尾：几个会互相打架的地方理顺了。白名单不再是「填错就回默认」的死胡同，重置也不会再把你的站点一起清掉。

整帖图片全挂，会先自己重连一次

图床偶尔抽风，几张图一起失败，控制台里报的是连接被重置——地址本身没问题，重连一下常常就回来了。以前一挂就弹「原帖图片加载失败 [重试]」，得你手动点。

现在先自动重连一次，恢复就直接出图、什么提示都不弹；重连完还是全挂，才给失败提示和重试按钮。每帖只自动重试一次，不会一直刷。

「重置」不再连同白名单一起清掉

以前点「恢复默认」，白名单会被整个删掉、回落到内置的五个域名。如果你的站点不在那五个里，重置完脚本在页面上就完全不动作，看着像坏了。

现在白名单单独留着，其它设置照常清空。代价是「恢复默认」不再是最彻底的那种重置，但不会把你自己的站点弄丢。

白名单里乱填，不会再被当成「清空」

以前在白名单框里填汉字、或者手滑带上端口号，保存之后名单静默变回默认，提示还写着「已保存」。现在是拒绝保存并指出哪几行不对，原来的名单一个字都不动。

白名单入口不绑当前站点

油猴菜单里的「🌐 白名单管理」现在不依赖你正打开的是哪个站。人在任何网页上都能打开它把域名加进去，不用先跑到那个论坛才能操作。

两个脚本抢排序参数，不再互相弹

同一个论坛上如果还装了别的脚本、它也在改排序参数，两边会互相把对方弹回原来的地址，页面就一直在刷新。现在脚本看一眼「这一跳是从哪儿来的」：如果是刚被弹回来的，就收手并提示，其它情况照常跳。

预览块的两处观感

  • 展开更早了：以前等图片下载完才撑开，现在浏览器一解出尺寸就撑开，起点高度也从 44 抬到 120px，不会只露一条缝。
  • 占位块看得见了：浅灰底上加了一层细内描边，能看出那是个框，不是一片灰砖。

1.6 还修了这几处

  • 预览块图片一直不出：服务端给的是相对地址，取链时却优先选中了它，拼不出完整网址。现在只认绝对地址，实在都是相对的就用同帖的域名补。
  • 慢图上来之后条带不展开：原来只等 30 秒，现在放宽到 180 秒，每帖各算各的。
  • 「恢复默认」把别的账号也清了：账号数据以前没先解析就判断，判断一直失败，最后退化成整个清空。
  • 点帖子图片退回论坛原生看图：接管点击的代码排在太后面，前面步骤一中断就整段跳过。
  • 单图加载层的三点被压扁：三点和「正在加载」挤在一行，改上下两行。
  • 自动翻页追加的页面不标已读；右键打开帖子也不记账，现在都补上了。
  • 论坛翻页后脚本报错：分页区重绘会把「下一页」链接冲掉，兜底逻辑找到的是 javascript:; 这种假地址，请求必然失败。现在用当前网址自己拼下一页。
  • 页码读不准：以前只认一种写法，伪静态页读不到，改成多级回退。
  • 限流时只报「网络错误」：现在能认出论坛的提示页，按它给的时间等。
  • 原帖图失效时提示太吓人：以前像整页坏了，现在整帖全挂压成一行说明，部分失败只删失败的格子。

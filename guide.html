01

认识与安装

萌宝小秘书是一份面向 Discuz 论坛的油猴脚本：把看图、翻页、过滤、收藏、评分和评论整理进同一套入口。数据保存在本地浏览器，不按“打开更多页面”来解决所有问题。

适合谁

需要连续浏览帖子、集中看图、跟踪收藏用户，或减少重复翻页与筛选动作的论坛用户。

不需要学什么

日常使用不需要读代码。先认四个球，再按页面支持矩阵判断哪个入口会出现即可。

这份只讲怎么用。参数、版本与验收回执看《总纲》；为什么这么定、踩过哪些坑看《成长感悟复盘》。

安装与更新

  1. 准备用户脚本管理器。使用支持 GM 存储与跨域请求能力的管理器，例如 Tampermonkey。直接把文件当普通网页 JavaScript 运行，不等同于安装油猴脚本。
  2. 安装现役脚本。通过项目仓库中的 mengbao.user.js 安装，或在管理器中新建脚本并粘贴完整源码。确认版本为 1.7（正式版）。
  3. 检查站点白名单。已预置 2 个论坛域名，只在这些域名下介入。若站点不在名单内，可通过管理器菜单添加；不要在不了解结构时把脚本放到所有网站运行。
  4. 打开一个支持的版块列表。确认悬浮球出现、看图能生成预览、设置保存后刷新仍保留，再开始使用。
  5. 更新前导出配置。覆盖安装同一份脚本通常可保留管理器中的数据，但换浏览器、换设备、清理站点数据或改变存储命名空间前，应先导出。

收藏、评分、已读和设置等数据保存在本地；脚本运行时可能按管理器规则加载已声明的依赖。

为什么列表页没有增强球

增强球只服务帖子详情；列表页的看图、翻页、过滤分别由自己的球承担。功能按目的归类，不按“这个按钮放在哪里”归类。

04

四个悬浮球：操作与状态

默认位置

四个球直径均为 44px，默认左边距 24px；自下而上的默认底边距离为：翻页 200px、看图 280px、增强 360px、过滤 720px。它们只在各自目标页面出现。

翻页球

左键加载一页，内容追加而不整页刷新；右键按设定延时持续加载，再右键停止。

列表页底部的论坛原生「下一页」按钮也被接管：点击不再整页跳转，改走同一加载逻辑，加载后地址栏页码与按钮的 curpage 同步。

球下标签显示这次翻到了第几页：从进入时的页码起算，追加成功一页加一；失败、一行没追加、手动跳页都不计数，刷新后从当前页重算。它不读论坛的总页数。

只走真实的下一页链接；分页被重绘后会重新定位，不把伪链当目标。

看图球

左键开启持续看图，再左键停止；右键停止并收起。收起后再左键只展开预览，不会自动重启持续加载。

翻页新增的帖子会由观察器补入当前持续轮次；每轮重新计算进度与停滞时间。

增强球

左键打开详情功能面板；右键切换评论面板。

购买、回复、链接与附件按钮按帖子实际内容生成；找不到可见目标时不应硬造入口。

过滤球

左键打开板块面板：左键条目隐藏，右键条目只看该板块；只看可叠加多个板块。右键球编辑标题规则。面板条目名称在左、计数胶囊贴右，两端对齐；长板块名自动省略。

被隐藏板块不再抓图预览，减少无效请求。过滤配置按账号保存。

标题屏蔽词：每行一条

写法含义示例与边界
广告标题包含该文字就隐藏普通包含匹配
=求资源标题完全相等才隐藏适合精确标题，不做模糊扩展
/公告/按正则匹配，忽略大小写非法正则被忽略并报告，其余规则照常
!置顶排除规则，命中后不隐藏优先于隐藏规则，用于抵消误杀

带板块 ID 的页面可选择“仅过滤当前板块”；否则规则全局生效。保存立即重排，取消不写入。

05

看图与画廊

列表预览带

  • 每帖默认先显示 3 张，可设 1–12 张；更多图片通过末尾“+”进入画廊。
  • 缩略图高度默认 200px，可设 120–320px；尚未展开时，执行代码使用的起点高度是 120px。
  • 滚动前会提前取图；抓页请求走同一个全局请求池（并发 4、间隔 80ms、同地址 60 秒内复用），当前帖优先于翻页与热度。
  • 持久化缓存上限 4000 帖；页面上已渲染的预览块上限 3200 个；超出后淘汰最旧的，滚回去不用重新请求帖子。预览缓存只是提速，不是长期备份。

异常图如何处理

情况脚本处理用户看到什么
整帖图片首次全失败等待 1 秒后自动重载一次，每帖仅一次若恢复，不弹错误；仍全挂才出现一行提示
部分图片失败移除未解码成功的图，不影响同帖其他图成功图片继续显示
真挂图持续探测窗口上限 180 秒超窗后给“原帖图片加载失败”和“重试”
帖子本来没图不进入无意义重试显示无图提示

画廊与单图

  • 画廊网格常规为 5 列，窗口变窄时依次降为 3 列、2 列；背景与卡片色可在设置中调整。
  • 滚轮切换图片，Ctrl + 滚轮缩放；缩放范围 0.3×–5×，放大后可拖动平移。
  • 支持顺时针 90° 旋转、底部缩略条定位；Esc 关闭画廊，双击图片或点击规定的空白 / 顶栏区域退出单图。
  • 图片加载超过 3 秒才显示慢加载提示，避免正常图片也频繁闪状态。
06

帖子详情、评分与评论

增强功能面板

画廊、收藏与评分是固定入口；购买、回复、链接、附件等按当前帖子条件出现。“收藏帖子”与作者名旁的“收藏用户”是两套数据，不要混用。收藏结果按论坛真实返回判定，成功、已收藏、失败会分别提示，不一律报成功。

评分会预填各评分项上限

点击评分会打开论坛原生窗口，读取各评分项上限并预填；一旦用户手动改分，后续补写立即停止。提交仍由论坛原生窗口完成，脚本接管成功 / 失败回调并记录状态。

评论面板

  • 右键增强球打开或关闭；面板可翻页、跳页、加载后续评论。
  • 默认宽度 24%，范围 15%–50%；最小字数默认 1，范围 1–30，两项均按账号保存。
  • 评论正文、头像、楼层、时间和跳转链接按真实返回渲染；长度过滤会显示被过滤条数。
  • 面板中的用户名右键跳转与全局“右键点击用户名”设置一致；选“关闭”时交还原生菜单。

详情页没有看图球

正文图片点击后直接进入本帖画廊；增强球负责打开完整功能面板。两条入口目标不同，不互相替代。

07

收藏馆、头像与昵称

收藏馆只管理“人”

  • 从设置中的收藏馆入口打开；显示当前账号的用户数与分组数。
  • 拖动用户胶囊可排序，拖到分组标签可归组；“全部”和“未分组”是内置视图，不按普通分组删除。
  • 编辑模式支持全选、批量移组、批量取消收藏；删除有确认，不可撤销。
  • 自定义分组可新建、改名、删除；重名会被拒绝，删除分组后组内用户回到未分组。
  • 收藏馆底部“导出 / 导入”只处理收藏用户与分组，不等于全量配置备份。

头像与昵称

  • 头像设置同时服务评论面板和收藏馆；昵称用于面板标题与提示。
  • 最多保存 9 个自定义头像，可拖拽调整位置；本地上传单图超过 5MB 会被拒绝。
  • 上传时压缩到 256px 保存。
  • 抓取头像会按候选地址依次尝试，并设置请求超时，避免单个地址挂起。
  • 头像库本身不纳入全量导出，重要图片请自行保留原文件。

多账号、备份、导入与恢复默认

哪些数据按账号分桶

收藏帖、收藏用户 / 分组 / 顺序、评分、已读、头像与昵称、评论面板宽度和最小字数、四球位置与折叠状态、过滤配置，以及配色、预览数量与高度、排序、已读开关与底色、翻页延时、跳转目标等个人设置，均按账号保存。白名单、调试开关、看图预览缓存与内部状态不随账号分桶。

账号识别不止一种方式

脚本结合页面 UID、个人入口与域名映射识别账号；无法确认时使用 guest 桶，并保留后续重新解析机会。UID 映射用于跨页面衔接，恢复默认时保留。

全量导出实际包含什么

包含

  • 通用与看图设置
  • 收藏帖、评分、收藏用户 / 分组 / 顺序
  • 白名单
  • 四球位置与折叠状态
  • 已读历史
  • 面板选择、昵称等已登记备份的设置项

不包含

  • 自定义头像库
  • 看图预览缓存
  • 未登记为备份键的临时界面状态

只导出真正设置过的值，不为空键写一串 null。

导入与恢复默认

  • 同账号导入：按设置规则校验并合并覆盖；未知键或非法值会触发整批回滚，旧版明确下线的键则忽略。
  • 跨账号导入：跳过收藏帖、评分和已读历史，其余通过校验的设置可写入当前账号或全局存储，避免把原账号状态串过来。
  • 恢复默认：保留站点白名单与 UID 映射；账号分桶数据只删除当前账号桶，不清空其他账号。完成后自动刷新。
  • 清除缓存 / 重置位置：分别只处理预览缓存和四球位置，不等于恢复默认。
10

现役现状与使用边界

这一节列出使用中值得提前知道的边界，以及仍需要真实现场才能继续判断的事项。

其他应知道的边界

  • 脚本只针对当前站点维护，选择器按该站实测 DOM 确定，不承诺兼容其他 Discuz 论坛；白名单可以添加别的域名，但换站后功能是否可用需重新验证。
  • 详情页若返回明显异常的总页数，目前只有按回复数重算的兜底，原始异常根因仍需真实现场。
  • 图床连接重置或 HTTP/2 协议错误可能自动恢复，所以首次全挂不等于图片永久失效。
  • 翻页追加、窗口重新聚焦、标签页重新可见及 pageshow 恢复时，都会尝试补标已读。
  • 热度与已购进页时逐帖取一次，一页约几秒；热度不到显示门槛的帖子不显示，购买数只有标价出售的帖子才有；后台有短时间软缓存，不会每次进页都重复请求。详情页取不到时会重试一次；旧记录缺的字段会被新值补齐。已判「已购 0」的售卖帖停留本页不会自动刷新数字，需刷新页面、翻页或重进后才重新抓取。详情页标题行的标签与列表同源，进帖即出数，不再额外发请求。

常见问题

球一个也没出现
先核对域名白名单与页面支持矩阵，再确认管理器已启用脚本。首页、个人中心等页面本来就不会主动出现球。
只看到部分球
这是正常行为。过滤球只在搜索 / 导读，增强球只在详情页，其余页面按矩阵出现。
翻页提示不是列表或需要登录
脚本会区分列表响应、论坛提示页与限流页。先确认登录状态，再适当增大翻页延时；不要把所有非 200 或 200 提示页都当末页。
持续翻页被限流
脚本会读取论坛提示与 Retry-After。连续限流时停止并调大延时，比反复手动重试更安全。
整帖图片全挂
先让自动重载完成；仍失败再点该帖“重试”，清除该帖缓存并重新抓取。旧帖图链确实失效时，重试也不能恢复原图。
设置改了但预览没变
预览数量 / 高度作用于后续渲染。刷新或继续翻页后再看；配色、已读与宽版则按表中的时机生效。
换账号后数据不对
先确认页面已识别到 UID，不要急于反复导入。跨账号导入会跳过收藏、评分和已读；其余数据按分桶规则读取。
准备换浏览器
先导出全量配置，并单独导出收藏馆名单；头像库和预览缓存不在全量导出中，重要头像原图另行保存。
热度 / 购买数没显示
先确认设置里「帖子热度与已购」已开启；刚进页需逐帖取数，等几秒再看。热度不到门槛的帖子不显示，非标价出售的帖子没有购买数；被屏蔽或只看过滤掉的行不进取数队列。已判「已购 0」的帖停在本页不会自动变，刷新、翻页或重进后才重抓。
需要排查日志
在设置中开启“调试日志”，复现问题后查看控制台。截图适合确认视觉状态，文本日志与真实 DOM / 返回适合确认数据。
